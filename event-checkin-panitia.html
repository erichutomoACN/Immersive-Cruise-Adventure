Langkah 1 dari 3 — Buat Google Sheet
Siapkan Google Sheet sebagai database
  1. Buka sheets.google.com → buat spreadsheet baru
  2. Beri nama bebas, misalnya: Event Check-in 2024
  3. Klik menu Extensions → Apps Script
Buka Google Sheets ↗
Langkah 2 dari 3 — Pasang Script
Paste kode backend ke Apps Script
  1. Di editor Apps Script, hapus semua kode yang ada
  2. Download file appsscript.gs yang saya sediakan, lalu paste isinya
  3. Klik 💾 Save (Ctrl+S)
  4. Klik tombol Run → pilih fungsi setupSheets → klik Run
  5. Klik Deploy → New deployment
  6. Type: Web app · Execute as: Me · Who has access: Anyone
  7. Klik Deploy → izinkan akses → salin URL web app
